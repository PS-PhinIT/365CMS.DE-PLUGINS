# 365CMS | Beratung

Landingpage-Builder für Beratungsleistungen rund um Microsoft 365, Copilot, KI, Security und Compliance – mit Bereichs-Baukasten, zentralen M365-FAQs, Kontaktformular, SEO-Ausgabe und Design-Presets.

- **Voraussetzungen:** 365CMS 4.0.0, PHP 8.4.1
- **Admin:** `/admin/plugins/cms-beratung` (Übersicht, Landingpages, Formular-Anfragen, M365 FAQs, Design-Presets, Globale Einstellungen, Import & Export, Hilfe)
- **Öffentlich:** `/beratung/<slug>` (auch `/en/…`), Standalone-Varianten unter eigenem Slug, Admin-Vorschau `/beratung-vorschau/<id>`
